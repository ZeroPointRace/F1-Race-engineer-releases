# 🏎️ F1 ZeroPoint Race Engineer

Magyar nyelvű, valós idejű **versenymérnök** az EA Sports **F1 25**-höz
(alap + 2026 Season Pack DLC). Élő telemetria, stratégia- és gumikezelési
tanácsok, hangos mérnök, élő pályatérkép.

---

## ⬇️ Letöltés (mindig a legfrissebb verzió)

👉 **[F1 Race Engineer telepítő — legfrissebb verzió](https://github.com/ZeroPointRace/F1-Race-engineer-releases/releases/latest)**

Az **„Assets"** alatt kattints a `F1-Race-Engineer-Setup-x.y.z.exe` fájlra.
A telepítés **egykattintásos**, és a program ezután **automatikusan frissül**
— a következő verziókat magától letölti és felajánlja.
